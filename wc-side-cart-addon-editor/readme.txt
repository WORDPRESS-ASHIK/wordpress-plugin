=== WC Side Cart Add-On Editor ===
Contributors: custom
Tags: woocommerce, product addons, side cart, xootix, variable product
Requires at least: 6.0
Requires PHP: 7.4
Stable tag: 1.2.0

Allows customers to edit WooCommerce Product Add-Ons from Xootix Side Cart and provides a "Select Option" popup modal for variable products to quickly configure attributes and add-ons and add directly to cart.

== Requirements ==
* WooCommerce
* Side Cart WooCommerce by Xootix
* WooCommerce Product Add-Ons (optional, for add-on field support)

== Features ==
* **Variable Product Quick-Add Modal**: Changes "Add to cart" / "Select options" button on variable products to "Select Option". Clicking it opens a modal allowing customers to select variation attributes, customize add-ons, adjust quantity, and add to cart without page reloads.
* **Side Cart Add-On Editor**: Lets customers edit configured product add-ons directly inside Xootix Side Cart.

== Supported add-on types ==
* Multiple choice / select
* Radio buttons
* Checkboxes
* Custom text
* Textarea
* Custom price / numeric input / multiplier

== Installation ==
1. Upload `wc-side-cart-addon-editor` to your plugins directory.
2. Activate the plugin in WordPress Admin.
